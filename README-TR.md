## <a id="about"></a>📋 Hakkında

**Kintaro Links**, sosyal medya varlığınızı şık bir şekilde sergilemek için tasarlanmış kişiselleştirilmiş bir landing page'dir. Dinamik arka plan görselleri, entegre müzik çalar ve atmosferik efektlerle sürükleyici bir deneyim sunar.

## <a id="features"></a>✨ Özellikler

### 🎧 Sürükleyici Ses Deneyimi

- **Click-to-Enter Overlay**: Müzik çalmayı başlatan sinematik bir giriş deneyimi.
- **Dinamik Ses Kontrolü**: Hover etkileşimlerine sahip pürüzsüz ses slider'ı.
- **Sesi Kapat/Aç**: Ses kontrolü için hızlı geçiş.

### ❄️ Atmosferik Efektler

- **Kar Yağışı Sistemi**: Görsel havayı zenginleştirmek için açılıp kapatılabilen, yüksek performanslı parçacık kar efekti.
- **Gerçek Zamanlı Bildirimler**: Efektler açıldığında veya kapatıldığında anlık geri bildirim.

### 🔗 Sosyal Medya Hub

- **Akıllı Link Grid'i**: Link sayısına bağlı olarak grid ve kolon görünümleri arasında otomatik geçiş yapan responsive düzen.
- **Animasyonlu Etkileşimler**: Tüm sosyal medya ikonları (Discord, Steam, TikTok, Instagram, Spotify, GitHub) için hover efektleri ve geçişler.

### 🎨 Premium Tasarım

- **Glassmorphism UI**: Bulanık arka planlar ve şık kart tasarımları ile modern estetik.
- **Tamamen Responsive**: Masaüstü ve mobil cihazlar için optimize edilmiş.
- **Dark Mode Estetiği**: Üst düzey görsel çekicilik için tasarlanmış derin, özenle seçilmiş renk paleti.

## 🛠️ Teknolojiler <a id="technologies"></a>

Proje, hız ve geliştirici deneyimine odaklanan modern bir geliştirme yığını kullanmaktadır:

- **React 19**: Dünyanın en popüler UI kütüphanesinin en son özelliklerinden yararlanır.
- **Vite**: Işık hızında geliştirme için yeni nesil frontend araçları.
- **React Icons**: Sosyal medya ve UI öğeleri için kapsamlı ikon seti.
- **Vanilla CSS**: Ağır framework'lerin yükü olmadan özel, optimize edilmiş stil yönetimi.

## 🚀 Kurulum <a id="installation"></a>

Projeyi yerel bilgisayarınızda çalıştırmak için aşağıdaki adımları takip edebilirsiniz:

1. **Depoyu Klonlayın:**

   ```bash
   git clone https://github.com/xkintaro/kintaro-links.git
   cd kintaro-links
   ```

2. **Bağımlılıkları Yükleyin:**

   ```bash
   npm install
   ```

3. **Geliştirme Sunucusunu Başlatın:**
   ```bash
   npm run dev
   ```
   Tarayıcınızda `http://localhost:5173` adresine giderek projeyi görüntüleyebilirsiniz.
